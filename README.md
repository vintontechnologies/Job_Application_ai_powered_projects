# AI Job Assistant

A Django web application designed to streamline job searching, tracking, and AI-powered assistance.

## 📁 Repository Structure
- **`accounts/`** – User authentication & profile management
- **`ai_engine/`** – AI workflows (resume evaluation, custom responses)
- **`applications/`** – Job application tracking
- **`jobs/`** – Job listings & discovery
- **`core/`** – Project settings & central routing
